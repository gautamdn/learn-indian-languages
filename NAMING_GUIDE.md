# Naming Updates for Multi-Language Support

## 🎯 Why the Change?

**Old:** "Kannada-Hindi Learning App"  
**New:** "Learn Indian Languages"

**Reason:** You plan to add Gujarati and other Indian languages, so a generic name is more scalable!

## 🚀 Using the New Name

### GitHub Repository
When running `setup.sh`, it will suggest:
```
Repository name [learn-indian-languages]:
```

Just press Enter to use the default, or type your preferred name.

### Netlify Site Name
Suggested names:
- `learn-indian-languages`
- `indian-languages`
- `family-languages`

Your URL will be: `https://your-site-name.netlify.app`

### Custom Domain (Optional)
Good domain names:
- `learnindian.com`
- `indianlanguages.app`
- `familylanguages.com`
- `heritagelanguages.com`
